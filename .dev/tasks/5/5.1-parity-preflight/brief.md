# Brief: 5.1-parity-preflight (этап 5: паритет поставки — bare-Ubuntu одной командой + сценарная приёмка)

## Goal (statable, checkable)

Довести поставку gfctl до инвариантов И1–И3 (SPEC «Инварианты поставки»):
`git clone → ./gfctl use <профиль>` работает на **голой Ubuntu** (apt-декларации
podman/podman-compose + GPU-подготовка хоста), класс сбоев AppArmor/pasta
teardown снят CONTAINERS_CONF-скоупом slirp4netns, судьба orphan-heal решена и
реализована (или отклонена с обоснованием), сценарные последовательности
`gfctl off; hfctl on` / обратная зафиксированы как контракт EXP/деплой-окон
(И2). Приёмка живьём — внешняя (окно, два отдельных GO по D6), в этом же окне
закрываются перенесённые хвосты (EXP-010/011/012, ребут/рестарт-приёмы fix-r2).

## DoD (checklist; единственный носитель DoD)

1. **Preflight apt**: идемпотентная установка podman + podman-compose при
   отсутствии (passt/slirp4netns/uidmap приезжают Depends podman); нет
   sudo/apt/сети → громкий отказ с внятным действием (не тихий skip).
2. **GPU-подготовка**: группы render/video + limits.d memlock — гейт по
   `/dev/kfd`|`/dev/dri`; при добавлении групп — честное «нужен перелогин»;
   семантика кодов выхода согласована с существующим memlock-гейтом
   (8388608, exit 42); зеркало hfctl 13.2 (не дублировать существующий
   limits.d-файл 4.x — merge-логика).
3. **Slirp-скоуп**: gfctl-команды используют CONTAINERS_CONF со скоупом
   slirp4netns; хранилище общее (образы/контейнеры видимы), hfctl-прод на
   машине НЕ задет (скоуп только для gfctl-вызовов); класс «signal deny /
   already in use / teardown-падений» убран.
4. **Orphan-heal — РЕШЕНИЕ зафиксировано в task.md** (пользователь ратифицирует
   на эскалации): либо `containers-storage delete-container` по ID из ошибки
   (условия срабатывания безопасные), либо отклонение с обоснованием
   «первопричина ушла со скоупом».
5. **Сценарный контракт И2**: EXP-скрипты фиксированных последовательностей
   (`gfctl off; hfctl on` и обратная; bare-install на голой машине/VM —
   ресурс решает пользователь) — из GitHub-клона (И3), без ручных мутаций;
   диагностические ЧТЕНИЯ разрешены. Скрипты созданы, НЕ запущены (D6).
6. **Батарея**: новые preflight/slirp-ассерты (faux-режим без реального apt) —
   зелёные; существующая (381) не сломана; `bash -n`; `py_compile`.
7. **SPEC honesty той же дельтой**: §2 (первичная установка — apt/GPU-шаги),
   §3 (install/use — обновлённый preflight), «Инварианты» — соответствие
   И1 из «частично» → полное (дата ревизии), чек-лист «Этап 5» —
   отмечены кодовые пункты (приёмочные — после окна); `spec_validate`.
   AGENTS.md (bootstrap-абзац) — обновить, если расхождение.

## Constraints and known traps

- Idempotency: bootstrap/preflight выполняется при КАЖДОМ вызове — apt-шаг
  обязан быть «уже стоит → 0 действий», никаких повторных apt-get update
  без нужды (дорогой сетевой шаг — только если пакет отсутствует).
- Границы доверия: отсутствие sudo/apt — громкий отказ (rc≠0, внятный
  рецепт), НЕ тихий пропуск; не выдумывать результат установки.
- Общее rootless-хранилище с hfctl: CONTAINERS_CONF-скоуп не должен создать
  ВТОРОЕ хранилище (иначе образы «пропадут» из виду) — скоуп через env
  только для gfctl-процессов; живой hfctl-прод не трогать (правило окон).
- Существующий limits.d-файл 4.x не задваивать; группы render/video —
  только при наличии /dev/kfd|/dev/dri (не на голой VM без GPU).
- «Перелогин» после group-add: честная диагностика (id -nG), не фейк-зелёный.
- И3: tar/cp из воркспейса разработчика запрещены — EXP-скрипты на машинах
  работают из GitHub-клона; локальная проба apt допускается только в
  ocbox-контейнере как dev-проверка (не результат приёмки).
- Bare-Ubuntu приёмка требует голой машины/VM — РЕСУРС НЕ ОПРЕДЕЛЁН,
  эскалация пользователю (варианты: VM на одной из машин / временный бокс /
  отложить до окна). Не выбирать молча.
- EXP-чек-лист (F21/F23): remote-часть с bootstrap; без параллельных
  прогонов; linger-восстановление в последовательностях (F11).
- Роли: только stdlib bash/python; python — не для этого подэтапа (shell =
  оркестратор apt/systemctl/файлы, принцип 4.4); не коммитить, STATE.md не
  править, llm-lab и /workspace/gufo — только чтение.
