   заложен плоский путь с комментарием; SKIP×5 — PASS-критерий №1, расход
   всплыл бы сразу.

   в product-журнале не сохраняются** (каждая попытка = recreate, podman logs
   wiped; журнал probe хранит вердикты, не цифры). Для PLAN-DoD «отказ с
   цифрами» оба EXP снимают цифры отдельной явной попыткой верхней ступени
   (`--context 262144` / `--context 196608`) ДО probe. Прод-код не менялся —
   считаю корректным (цифры нужны для отчёта окна, не для работы CLI);
   опциональный бэклог: писать хвост лога отказавшей ступени в журнал probe.
