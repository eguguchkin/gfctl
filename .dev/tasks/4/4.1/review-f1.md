## Blocking

1. **`EXP-008-delivery.sh:70` (+ использование :83, :106): `GF_ACC_FLAVOR` не доезжает до remote-части.**
   Что: `ssh … 'bash -s' <<'REMOTE'` — ssh (BatchMode) не пересылает локальные env; heredoc
   закавычен (локальной подстановки нет); remote `set -u` (:71). Первое обращение
   `setname=${GF_ACC_FLAVOR%%-*}` (:83) → «unbound variable» → remote падает rc=1 (вне легенды
   44/45/46/54/47/48) сразу после bootstrap/uninstall, до install и save. Окно доставки
   гарантированно RESULT: FAIL при любом раскладе.
   Что должно быть: домовой паттерн EXP-007:93 (сам баг уже чинился в EXP-007 — урок потерян):
   `$SSH "$GF_ACC_USER@$GF_ACC_HOST" "GF_ACC_FLAVOR=$GF_ACC_FLAVOR bash -s" <<'REMOTE'`
   (heredoc остаётся `'REMOTE'`; переменная раскрывается локально в аргументе ssh).
2. **`EXP-008-delivery.sh:103`: digest-подсказка снимает не тот digest.**
   Что: `podman inspect --format '{{.Image}}' gufo` возвращает image ID (bare 64-hex,
   config-ID), а не digest манифеста — docs.podman.io (podman-container-inspect): `.Image` =
   «Container image ID (64-char hash)», `.ImageDigest` = «Container image digest
   (sha256:+64-char hash)». Пин `repo:tag@sha256:<config-ID>` из реестра неразрешим (pull по
   digest работает только с digest манифеста) → страховка от смерти ghcr, ради которой сделан
   шаг, при использовании подсказки молча не сработает (podman pull — «manifest unknown»).
   Что должно быть:
   `echo "запинить: GFCTL_IMAGE=$IMG@$(podman inspect --format '{{.ImageDigest}}' gufo)  (подсказка НА ГЛАЗ — канон gfctl не меняется)"`
   — `.ImageDigest` уже содержит префикс `sha256:`, захардкоженный `sha256:` убрать.
   (Имя контейнера `gufo` = CONTAINER default — корректно; дефект только в поле шаблона.)

Оба пункта — однострочные правки одного файла; `bash -n` после правки; батарея EXP не
покрывает (заготовка), регресс не затронут. Продуктовый код (lib/, gfctl) — без блокеров.

## Non-critical notes (не блокируют; backlog)

   мусором при непустом `.part`, curl может перезаписать содержимое → resume пина даст смесь →

   только при криво настроенном зеркале. Бэклог: `mv part part.pre-mirror` перед зеркальной
   попыткой (rename мгновенный на том же fs), если когда-нибудь укусит.

4. EXP-008: `IMG` захардкожен `…:latest` — совпадает с дефолтом канона (форки запрещены,

   контейнера `gufo`.

   §4 при следующем касании SPEC (не блокер: env опциональный, дефолт = прежнее поведение,
   sha-арбитраж и «размер + sha256 до и после» §3 не изменены).
