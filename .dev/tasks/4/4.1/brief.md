# Brief: 4.1 хардening + локальная доставка (этап 4, код-часть)

## Goal
Финальный сабстэдж: doctor видит «ручные» артефакты окон, install
идемпотентен поверх работающего, uninstall-слои с безопасными границами
purge, EXP-008 (доставка с нуля на обеих машинах) и EXP-009 (ребут-приёмка)
подготовлены как заготовки. Окна — по GO, вне этого сабстэджа.

## Scope (код)
1. **doctor: блок «соседние артефакты»** — обнаружение и печать (БЕЗ
   действий): `~/gufo-models` (исходники весов окон — НЕ трогать никогда),
   `~/gufo-exp`, `~/halogen-models`, `~/halogen-cache` + приёмочные
   `~/gfctl-acc*`. Назначение: пользователь видит, что осталось от окон;
   uninstall НЕ должен их трогать (только приёмочные ~/gfctl-acc*).
2. **install идемпотентность поверх работающего**: если сервер healthy —
   НЕ recreate, только: до-проверка весов (SKIP), перегенерация юнитов,
   автозапуск; печатать «healthy — recreate не нужен». Если dead — штатный
   путь.
3. **uninstall границы**: без флагов: контейнер + юниты + timer + linger
   off + limits.d + ~/gfctl-acc{,-src,-models} (приёмочные) — НО:
   `~/gufo-models`, `~/gufo-exp`, `~/halogen-*` — НЕ ТРОГАТЬ никогда
   (выводить их список в конце uninstall «остались нетронутыми»).
   `--purge-models` — удаляет и ~/gfctl-acc-models УЖЕ удаляется
   без флага? — НЕТ: brief фиксирует: ~/gfctl-acc-models удаляется только
   с --purge-models (там могут быть докачанные 15-110 GB). Образ ghcr —
   только --purge-image.
4. **README quickstart финал** (4 команды от клонирования).
5. **EXP-008-delivery.sh** (заготовка): «доставка с нуля» на машину:
   (предусловие: gfctl не установлен или uninstall'нут) tar-перенос →
   install.sh → gfctl install (докачка только недостающего) → use канон →
   agent-check → **watch: 3 тика не-TTY на живом сервере (последний
   непроверенный живьём кусок 3.1)** → gfctl off. Параметры GF_ACC_*/FLAVOR. PASS: healthy+smoke
   + agent-check rc 0 + watch 3 тика rc 0.
6. **EXP-009-reboot.sh** (заготовка, ТРЕБУЕТ пользователя у машины):
   скрипт НЕ умеет ребутить — чек-лист для ручной ребут-приёмки:
   (1) gfctl off; (2) пользователь ребутит машину; (3) после загрузки:
   сервер сам healthy (таймер/boot-юнит); (4) smoke; (5) hfctl on.

## Out of scope
- Никаких изменений probe/bench/agent-check логики; pин/фикстуры не
  трогать; jq/новые зависимости запрещены.

## DoD
- [ ] doctor печатает блок артефактов (детерминированно на хосте без них —
      «не обнаружены»).
- [ ] install на healthy — без recreate (батарея: faux healthy → ровно 0
      podman run; dead → штатный run).
- [ ] uninstall: батарея — faux артефакты созданы → после uninstall
      ~/gfctl-acc* удалены, ~/gufo-models и ~/halogen-* НЕ удалены,
      список напечатан; --purge-models удаляет ~/gfctl-acc-models;
      --purge-image удаляет образ.
- [ ] README quickstart = 4 команды (SPEC §1), команды существуют.
- [ ] EXP-008/009 заготовки: bash -n, bootstrap-first, GF_ACC_* гейты,
      не исполняются; EXP-008 включает watch-тик на живом сервере
      (закрытие последнего непроверенного живьём куска 3.1).
- [ ] Батарея 289+N зелёная; регресс 1.1–3.1 цел.
