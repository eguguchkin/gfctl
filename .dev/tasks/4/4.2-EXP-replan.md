## Открытые вопросы

Блокирующих нет. Неблокирующие:

1. **Состав пулов весов** — по документам непротиворечив (evo: 27b-сет +
   запасные руки квантов; FAEX: flash-сет уже в acc-models с EXP-005 + пул
   закачек), но финальная сверка — на месте в окне: скрипт печатает `du`/`ls`
   до линковки. Лишние .gguf пула линкуются безвредно (0 байт, тот же инод;
   движок грузит только файлы serve_args; install SKIP-ит строго по пинам
   размер+sha).
2. **flash-multi на evo** — RAM-гейт отсечёт до трафика (без изменений);
   выбор машины/флейвора — за GO пользователя на окно.
3. **memlock под ai** — install сам ставит `limits.d/99-gfctl-memlock.conf`
   по порогу 8388608 (4.1-F2 реализован): WARN «перелогинься» не прерывает
   install, exit 42 только ниже порога. Отражено в шапке EXP-008; отдельный
   PREREQ-шаг не нужен.

  hfctl-прод (`hfctl on` → healthy + smoke).

  gfctl on); после ребута — gfctl-serve active, статус дошёл до health: ok в
  wait-loop ≤12 мин, «DEVICE_MISMATCH: нет», «роут:» из лога, «SMOKE: OK»,
  ручных команд 0; hfctl-прод возвращён — HFCTL_HEALTH=health: ok (или
  absent при отсутствии hfctl) + linger=yes.
